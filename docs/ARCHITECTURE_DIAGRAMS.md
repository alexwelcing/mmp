## 🔐 Security Model

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                            SECURITY LAYERS                                       │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  LAYER 1: NETWORK SECURITY                                                       │
│  ┌───────────────────────────────────────────────────────────────────────────┐  │
│  │  • VPC with private subnets (no public IPs on nodes)                      │  │
│  │  • Cloud Armor WAF (DDoS, SQLi, XSS protection)                           │  │
│  │  • Private Google Access (egress to GCP APIs only)                        │  │
│  │  • Firewall rules: deny all egress except 443 to GCP                      │  │
│  └───────────────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  LAYER 2: CLUSTER SECURITY                                                       │
│  ┌───────────────────────────────────────────────────────────────────────────┐  │
│  │  • GKE Workload Identity (no service account keys in pods)                │  │
│  │  • gVisor sandbox for GPU workloads (container isolation)                 │  │
│  │  • Binary Authorization (optional: only signed images)                    │  │
│  │  • Node auto-upgrade (latest security patches)                            │  │
│  └───────────────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  LAYER 3: APPLICATION SECURITY                                                   │
│  ┌───────────────────────────────────────────────────────────────────────────┐  │
│  │  • Secrets in GCP Secret Manager (not ConfigMaps)                         │  │
│  │  • CORS configured for specific origins (not *)                          │  │
│  │  • API rate limiting per IP                                               │  │
│  │  • Input validation (Pydantic models)                                     │  │
│  └───────────────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  LAYER 4: BLOCKCHAIN SECURITY                                                    │
│  ┌───────────────────────────────────────────────────────────────────────────┐  │
│  │  • ERC-4337 Account Abstraction (users never touch keys)                  │  │
│  │  • Gasless onboarding via Paymaster                                       │  │
│  │  • CharacterNFT: one free mint per address                                │  │
│  │  • Immutable royalty splits (0xSplits)                                    │  │
│  └───────────────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────────────┘
```
